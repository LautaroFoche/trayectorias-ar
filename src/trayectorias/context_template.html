03 / Kids Online Argentina · UNICEF / UNESCO

Una generación conectada

Uso de redes, inteligencia artificial y experiencias digitales. Relevamiento: octubre–diciembre de 2024. Publicación: 2025.

Universo: estudiantes de 9 a 17 años en localidades urbanas de al menos 50.000 habitantes. Muestra: 5.910 estudiantes, 291 escuelas. Los resultados no representan a toda la niñez argentina ni permiten comparaciones provinciales. Son autorreportes, no mediciones de un efecto causal.

ChatGPT: acceso desigual

Porcentaje que lo usó alguna vez dentro de cada grupo. Edad y nivel socioeconómico son desagregaciones distintas; no se suman.

Cómo interpretar las señales

El 46% reportó al menos una experiencia de uso problemático. Dentro de ese grupo, el 50% percibió un menor rendimiento escolar asociado al uso de internet.

Ese 50% tiene un denominador condicionado. No equivale a la mitad de todos los estudiantes. La percepción reportada no permite atribuir causalmente una baja en calificaciones.

El 66% de quienes usaron ChatGPT lo utilizó para tareas escolares. Entre quienes lo usaron para tareas, el 69% lo consideró muy útil. Utilidad percibida tampoco equivale a aprendizaje medido.

05 / Ingeniería de datos

De la fuente a una publicación verificable

Descarga HTTPS → snapshots por SHA-256 → contratos Python → modelos y pruebas dbt → CSV / Parquet / DuckDB → web. Airflow orquesta el flujo; cada ejecución construye una versión aislada.

La publicación cambia de versión sólo después de completar las validaciones. Los PDF revisados están fijados por hash: si cambian, la ingesta exige una nueva revisión. Los nulos se conservan; las poblaciones y los años de las distintas fuentes no se mezclan.
