# Presentación del portfolio

TrayectoriasAR integra fuentes educativas y digitales argentinas con un pipeline auditable. Demuestra ingeniería de datos con Python, SQL, dbt, DuckDB y Airflow, y una web autocontenida para explorar continuidad escolar, conectividad, IA y evidencia PISA.

Mostrar: snapshots por hash; contratos para cuatro formatos; 13 modelos dbt; publicación atómica; replay offline; pruebas de nulos y comparabilidad; fuentes y denominadores visibles. Explicar por qué no se unen universos incompatibles ni se afirma causalidad.

Docker y Snowflake fueron ejecutados y validados: misma entrada y once tablas equivalentes entre motores. Explicar el monitor de consumo, la autenticación de servicio y las garantías de publicación. No afirmar una implementación productiva ni impacto medido sobre estudiantes. La salida principal es una web estática.
